# spacedrift brand kit

Logos, profile pictures, banners, post templates, web icons, guidelines and motion for **spacedrift.in**.
Every asset uses the site's palette and visual language and nothing else.

- **Colour:** white `#FFFFFF`, ink `#0A0A0A`, red `#E10600`. Ink at reduced opacity is used only for secondary text, hairlines (6% grid, 14% rules) and ASCII texture.
- **Shapes:** square corners, no gradients, no soft shadows. The one shadow allowed is a flat offset "stamp" in red.
- **Type:** Geist 600 (headlines, −0.045em) and Geist Mono (uppercase labels at +0.06em, and all ASCII). The fonts come from the official `geist` npm package.
- **Story:** Noise → Parse → Model → Ship. Primary line: *We turn noise into ML systems **that ship.***

Everything here is generated by `src/`. To change something, edit a template and regenerate. Don't hand-edit the PNGs.

> **About file names:** a name gives the platform's **base size**, which also fixes the aspect ratio. The pixels inside are 4K-class.
> For example, `service-01-…-1080x1350.png` is a 4:5 post saved at **3456×4320**. Banner files are the exception: they are named by their real pixel size, and each comes as an exact-size version plus a 4K master.

## 01-logo/ (41 files)

| Lockup | What it is |
|---|---|
| `horizontal` | Mark + wordmark. The primary logo. |
| `stacked` | Larger mark above the wordmark, left-aligned. For square or tall spaces. |
| `mark` | The mark on its own: a 15u ink square with a 7u red square drifting off its top-right corner. |
| `wordmark` | "spacedrift" in Geist 600, −0.05em, with optical pair spacing. |
| `signature` | The wordmark with a red square as its full stop, as in the site footer. |

- `svg/spacedrift-{lockup}-{positive|negative|for-red}.svg` (15 files): outlined vector masters with no font dependency and transparent backgrounds.
  - `positive`: ink and red, for light backgrounds.
  - `negative`: white and red, for ink.
  - `for-red`: white and ink, for red.
- `svg/spacedrift-mark-site-20grid.svg`: the exact 20×20 mark used on the site.
- `png/spacedrift-{lockup}-{on-white|on-ink|on-red}.png`: solid backgrounds, 2X clear space, 3840px wide (the mark is 4096²).
- `png/spacedrift-{lockup}-transparent-{positive|negative}.png`: transparent, with exactly 1X clear space.

**Construction:** u = the ascender height of the wordmark ÷ 15, so the ink square matches the height of the "d". Clear space X = 7u, the size of the red square. Minimum sizes: mark 16px, horizontal lockup 96px wide.

## 02-profile/ (21 files)

The mark is centred so that its outer corners fall inside the central **70% circle**. Every platform crops the square to a circle, so none of it gets clipped.

- `white/`, `ink/`, `red/`: three colourways. The ink square turns white on ink; on red it is white with an ink accent.
- Each folder holds `master-4096`, `instagram-1080`, `threads-1080`, `facebook-1080`, `youtube-800`, `x-400` and `linkedin-400`. These match each platform's recommended upload size; X and LinkedIn also accept larger files.

## Regenerate

```bash
cd branding/src
npm install          # geist fonts, fontkit, and an optional static ffmpeg for motion
npm run render       # all PNG/SVG (~30s). Groups: npm run render -- logo profile banners instagram posts web guidelines
npm run motion       # 08-motion (~1 min)
npm run check        # verifies PNG dimensions, file size (<4 MB) and that every pixel is a white/ink/red blend
```

**Requirements:**
- Node 20+.
- Playwright and Chromium. The scripts use the global `playwright` package (`NODE_PATH=$(npm root -g)`) and browsers in `$PLAYWRIGHT_BROWSERS_PATH`, which defaults to `/opt/pw-browsers`.
- ffmpeg for motion. Set `$FFMPEG`, or rely on the optional `@ffmpeg-installer/linux-x64`, or have one on your PATH. Without H.264, motion falls back to VP8 `.webm`.

**Source layout:**

| File | Contents |
|---|---|
| `lib/fonts.mjs` | Geist `@font-face` rules, plus text → SVG outlines (fontkit). |
| `lib/logo.mjs` | Mark and lockup construction. |
| `lib/brand.mjs` | Page shell, grid, labels, the ASCII field canvas and terminal panels. |
| `lib/ascii.mjs` | Terminal scenes: noise, parse, model, ship, research, rag, web, mobile, annotate. |
| `lib/engine.mjs` | Playwright renderer. |
| `templates/*.mjs` | One file per folder. |
| `render.mjs`, `motion.mjs`, `check.mjs` | Entry points. |

**Fonts:** the renderer refuses to screenshot if Geist or Geist Mono fails to load, so a system font can't slip in silently. The ASCII glyphs used are checked against Geist Mono's character map.
